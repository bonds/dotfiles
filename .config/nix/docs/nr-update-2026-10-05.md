## Blockers found (all surfaced by ONE `nr --update` bumping everything at once)

1. **electron node-headers hash pin — REAL, fixed.**
   `node-v43.7.7-headers.tar.gz` fetchurl hash mismatch: specified `sha256-f8bSbLRmtbP93CJAvEBs+sHWDZ1xP2bcpLhC1EnOmZU=`, got `sha256-9pfO2UU+Q2YljtD/NXESLaN7o+ydNJvRbZGFaRThQPA=`.
   Cause: `modules/packages/hermes-desktop-fixed.nix` shim pinned `pinnedElectronVersion = "43.6.0"`; nixpkgs' electron moved to 43.7.7, so the shim URL no longer matched and the hardcoded pin inside the `hermes-agent` input (`nix/desktop.nix`) was used.
   Fix (in `modules/packages/hermes-desktop-fixed.nix:33,37`): `pinnedElectronVersion` → `43.7.7`, `servedSha256` → `sha256-9pfO2UU+Q2YljtD/NXESLaN7o+ydNJvRbZGFaRThQPA=`. Verified via `nix store prefetch-file` (real URL hashes to 9pfO2…) and a fresh eval producing that outputHash.

2. **anyio — REAL upstream test regression.** `python3.12/3.13-anyio-4.14.x` pytestCheckPhase fails: `tests/streams/test_tls.py::test_tls_connectable[*]` → `ValueError('server_hostname can only be specified in client mode')` (4 tests) + 2 `test_from_thread.py` unraisable-exception failures. Upstream regressed TLS tests in 4.14.x (IDNA / TLSStream.wrap, anyio PR #1208). Fix: overlay `modules/overlays/anyio/default.nix` sets `doCheck = false` (wired `modules/overlays/darwin.nix:33`).

4. **lix — test budget, not a failure.** `lix-2.95.2` installCheckPhase: `80/80 installcheck - lix:functional2 TIMEOUT 300.02s killed by signal 15 SIGTERM`; Ok 71 / Fail 0 / Skipped 8 / Timeout 1 — zero real failures, just the meson 300s test timeout on this machine. NOTE: an earlier attempt there used `mesonInstallCheckFlags = --timeout-multiplier=0`, which does NOT reach the functional2 pytest timeout — that was the wrong lever.

Failing tests are all spawn/cluster: `test-child-process-spawn-*`, `test-cluster-worker-*`, `test-child-process-http-socket-leak`, `test-benchmark-node-bench-tools`. Fix (NOT YET VERIFIED): overlay `modules/overlays/nodejs/default.nix` setting `doCheck = false` on `nodejs`, `nodejs-slim`, `nodejs_26`, `nodejs-slim_26` (the failing drv is the `_26` variant); wired `modules/overlays/darwin.nix`.

## Pattern / lesson
Four of the five are TEST-ENVIRONMENT failures on macOS (sandbox localhost, 300s test budget, spawn/cluster tests), not broken code. Only node-headers and anyio were real. A single `nr --update` jumped the lock very far, so each fix revealed the next. **Recommended policy: bump `flake.lock` deliberately and separately from code/config changes, so failures can be bisected.** Also consider a standing `doCheck = false` policy for heavy leaf packages whose tests are sandbox-hostile.

## Where it got to
Latest full build: `✔ 32` derivations, lix now PASSES, failure at nodejs test phase. Store is warm; remaining work was mostly test phases, ~5h per verification cycle.
Logistics note: subagent runs are capped at 3600s (`delegation.budget_max_seconds`, already at the schema max), and a full build exceeds that, so long builds must run in the user's own shell.
